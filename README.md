# OuRi Local AI

Локальный ИИ-чат для Android из экосистемы OuRi: модели работают **прямо на телефоне**,
без сервера и без интернета после загрузки модели. Чёрно-белый интерфейс в стиле QKC.

## Что внутри
- **Движок:** MediaPipe GenAI / LiteRT-LM (`com.google.mediapipe:tasks-genai`), arm64-v8a.
- **Загрузчик моделей:** честный прогресс в процентах и МБ, отмена, удаление;
  файлы лежат в приватной папке приложения.
- **Каталог моделей** (открытые и бесплатные, Hugging Face):
  | Модель | Квант | Размер | Источник |
  |---|---|---|---|
  | Qwen2.5 1.5B Instruct | INT8 | ~1.6 ГБ | litert-community |
  | Qwen3 0.6B | INT4 | ~0.5 ГБ | litert-community |
  | Gemma 3n E2B IT | INT4 | ~3.7 ГБ | зеркало сообщества |

  Про Gemma 2: Google изъял Gemma 2 из всех публичных on-device сборок LiteRT,
  поэтому в каталоге Gemma 3n — прямое продолжение линейки для телефонов.
- **Шаблоны чата** по семействам: Qwen (`user/assistant`) и Gemma (`<start_of_turn>`).

## Сборка
```
export JAVA_HOME=<jdk17> ANDROID_HOME=<sdk с platforms;android-34 и build-tools;34.0.0>
gradle assembleRelease          # heap держите <= 560m на машинах с 1 ГБ RAM
```
Подпись: свой ключ (в репозитории его нет); подписывайте тем же, что и прошлые
выпуски, иначе обновление не встанет поверх.

## Честные ограничения
- Только arm64-v8a (все современные телефоны).
- Первый запуск модели грузит её в память — до минуты.
- Скорость ответа зависит от телефона и кванта; INT4-модели быстрее.
- Приложение не подключается к старому ПК-серверу AI Chat: это полностью локальный продукт.
